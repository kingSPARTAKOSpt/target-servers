# target-servers

Lista pública de servidores do jogo **Target** (PraeliaLab), lida pelo menu do jogo.

URL: https://kingspartakospt.github.io/target-servers/servers.json

Formato:
```json
{ "minVersion": "0.1.0", "message": "...", "servers": [ { "name": "EU #1", "address": "1.2.3.4:7777", "region": "eu", "online": true } ] }
```
